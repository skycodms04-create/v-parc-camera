모델 로딩 시험

ONNX 로딩이 느린 문제를 줄이는 세 가지 방법을 잽니다. ← 카메라 시험

기기 정보

  • OS / 브라우저—
  • 폰에 저장된 모델—
  • 모델 런타임아직 안 켬

시험 1. 폰에 저장 + int8 비교

두 모델(int8 3.7MB, 원본 14MB)을 인터넷에서 새로 받을 때와 폰에 저장해 둔 걸 꺼낼 때를 비교합니다. 와이파이·데이터 중 평소 쓰는 환경에서 눌러 주세요.

시험 2. 반납 시작 화면에서 미리 받기

반납 시작 화면이 떠 있는 동안 모델을 미리 받아 두면, ‘주차 사진 찍기’를 누른 뒤 얼마나 기다리는지 잽니다. 페이지를 새로 열어서 잽니다.

저장된 모델이 있으면 저장본을 씁니다. ‘처음 쓰는 사람’ 기준으로 재려면 먼저 ‘저장된 모델 지우기’를 누르세요.

결과 (ms)

시험모델 · 받아온 곳크기MB받기준비첫 판단합계누른 뒤 대기
아직 결과가 없어요

받기 = 인터넷 다운로드 또는 저장본 읽기. 준비 = 모델을 메모리에 올리는 시간. 첫 판단 = 처음 한 번 돌리는 시간. 누른 뒤 대기 = ‘주차 사진 찍기’를 누르고 모델이 준비될 때까지 기다린 시간(시험 2).
